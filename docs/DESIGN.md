# Material You 3 — design references and decisions

## Offline references actually inspected

No web requests were made. The user's offline constraint takes precedence over cloud design workflows. The local Qt Quick Controls Material implementation supplies ready-made Material components and explicit links to M3 specifications:

- `/usr/lib/qt6/qml/QtQuick/Controls/Material/Button.qml`: full-scale rounded buttons, icon spacing, elevation and interaction states.
- `/usr/lib/qt6/qml/QtQuick/Controls/Material/TextField.qml`: outlined fields and primary-color focus states.
- `/usr/lib/qt6/qml/QtQuick/Controls/Material/Dialog.qml`: modal behavior, spacing, rounded scale, tonal surface and explicit Material 3 references.
- `matugen --help` and `matugen 4.2.0 --dry-run -j hex color hex '#4EF5E7'`: authoritative local CLI documentation and generated semantic roles.

Upstream links provided by the installed implementation, recorded for future work only (not fetched this session):

- https://m3.material.io/components/dialogs/specs
- https://m3.material.io/components/dialogs/guidelines
- https://m3.material.io/components/buttons/overview

No Qt source code was copied. The web components are original HTML/CSS implementations informed by these locally installed references. No external font, icon library, CDN, tracking, imagery or cloud canvas is used.

## Visual system

Use Material 3 semantic colors from `src/tokens.css`, not the seed color directly for text. The seed `#4EF5E7` produces readable primary `#006a63` in light mode and `#81d5cc` in dark mode. Generated output is preserved in `palette.json`; both schemes use matugen's default tonal-spot scheme. `--dry-run` prevents template rendering, application reloads, wallpaper changes and hooks.

The frame uses surface, navigation uses surface-container-low, selected items use secondary-container, and the editor uses surface-container-lowest. Primary-container highlights the main creation action. Full rounded buttons, 22px panels and a 28px modal express the rounded Material shape family. Focus rings and hover state layers remain visible in both themes. Reduced-motion preferences disable transitions.

The layout has a navigation drawer, note list and editing surface. At narrow widths the drawer becomes an overlay and the list becomes a horizontal strip above the document. The product is deliberately compact: one workspace, no fabricated teams, unread counters, remote presence, nested folders or nonfunctional feature teasers.

Original assets: `assets/logo.svg` (two neighboring strokes), `assets/orbit.svg` (thoughts orbiting a center), and a hand-authored 24px SVG icon set in `src/icons.js`. Raster screenshots are generated by the browser test. No image-generation service is required for these vector assets.

## Typography and interaction

Use the local system sans-serif stack, including Cyrillic; no downloaded fonts. Reading is the initial mode to keep the first screen calm; editing is one explicit pencil button away, and newly created notes open in editing mode. Toolbar actions enter editing mode automatically. Inputs, native buttons, dialog and checkboxes preserve keyboard behavior. Search shortcut: Ctrl/Command+K; text shortcuts: Ctrl/Command+B and I.

The Markdown renderer supports a documented subset rather than claiming full CommonMark. User HTML is always escaped, images are not interpreted, and only HTTP(S) links are allowed. Text persists synchronously after each input; no pending debounce can drop the last keystroke during navigation.
