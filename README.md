# Рядом — заметки

Первый этап: локальный фронтенд в стиле Material You 3. HTML, CSS и JavaScript без библиотек, сборки и загрузок из интернета. Использована существующая папка `frondent` (написание сохранено).

## Запуск

Для запуска фронтенда и C++ API одной командой из родительской папки:

```sh
./frondent/start.mjs
```

Сейчас у готового C++-бинарника отсутствуют динамические библиотеки; подробности и требования к PostgreSQL — в [инструкции общего запуска](docs/STARTUP.md). До подготовки бэкенда запускайте тот же скрипт с `--frontend`. Сам запуск API не подключает к нему локальный редактор.

Нужен уже установленный Node.js 20 или новее. Устанавливать npm-пакеты не требуется.

```sh
cd frondent
npm start
```

Открыть `http://127.0.0.1:4173`. Остановить — Ctrl+C. Если порт занят: `PORT=4174 npm start`. Не меняйте порт без необходимости: данные браузера привязаны к адресу, включая порт. Сервер слушает только loopback и не публикует приложение в локальной сети.

## Возможности

- Создание и редактирование заметок с сохранением в localStorage.
- Markdown: заголовки, жирный, курсив, списки, задачи, цитаты, код и HTTP(S)-ссылки.
- Чтение с интерактивными задачами; панель форматирования и клавиатурные сочетания.
- Поиск по названию и тексту, три сортировки, избранное.
- Корзина с восстановлением и отменой перемещения; копирование заметки.
- Скачивание заметки в `.md`, светлая и тёмная темы, адаптивный экран.

Серверная авторизация и совместное редактирование **ещё не подключены**. Кнопка «Поделиться» предлагает экспорт и объясняет ограничение. Данные не передаются C++-серверу. Примеры при первом открытии — редактируемый демонстрационный контент.

Очистка данных браузера удаляет заметки. Для важных заметок используйте «⋯ → Скачать Markdown». Данные не синхронизируются между браузерами и устройствами. Конфликт с другой вкладкой блокирует дальнейшую запись до перезагрузки: сначала скачайте текущую заметку. Размер хранилища ограничен браузером; при ошибке сохранения показывается предупреждение.

## Проверки

```sh
npm test
```

Для браузерных тестов нужны **уже установленные** Playwright и Chromium-совместимый браузер. Скрипт ничего не скачивает. Запустите приложение, затем:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
BROWSER_PATH=/absolute/path/to/browser \
node scripts/browser-test.mjs
```

Скриншоты и экспорт тестов находятся в `test-results/`, исключённой из Git. Тестовый браузер запускается со своим временным профилем; внешние запросы запрещены.

В установленном headless Vivaldi событие загрузчика не приходит. Для него добавьте `BROWSER_CAPTURE_EXPORT=1`: проверяется содержимое Blob, имя `.md` и вызов скачивания, а созданный Markdown сохраняется как артефакт теста. Это не проверка нативного менеджера загрузок. Без этого флага тест требует настоящее событие `download`.
