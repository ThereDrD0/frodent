# Рядом — доска для общих идей

Минимальная доска в стиле Material You 3: свободное полотно, текст, стикеры, рисунки, прямоугольники и вложения. HTML/CSS/JavaScript без библиотек и сборки. Системные шрифты, оригинальные SVG-ассеты, обе темы из matugen `#4EF5E7`.

## Запуск

Из папки `naroshno`:

```sh
./frondent/start.mjs --frontend
```

Открыть `http://127.0.0.1:4173`. Ctrl+C завершает только процессы этого скрипта. Нужен Node.js 20+, устанавливать npm-пакеты не требуется. Из `frondent` также работает `npm start`.

Для фронтенда и существующего C++-сервера вместе:

```sh
./frondent/start.mjs
```

Настоящий C++-бинарник сейчас требует недостающих библиотек и подготовленной PostgreSQL. [Инструкция](docs/STARTUP.md). Скрипт ничего не скачивает и не запускает системные службы.

## Что работает

- Перемещение полотна, масштаб колесом с Ctrl/⌘, кнопки масштаба, показ всей доски, жест двумя пальцами.
- Стикеры, обычный текст, прямоугольники и свободные штрихи; выделение, перетаскивание и изменение размеров.
- Двойной клик для текста; Delete, отмена и повтор; цвета и дублирование объекта.
- Изображения PNG/JPEG/WebP/GIF и документы PDF/Office/OpenDocument/TXT/MD/CSV/RTF через перетаскивание, выбор файлов и Ctrl/⌘+V. Документы показаны карточками, скачивание — двойным кликом. Встроенного Office/PDF-редактора нет.
- Файлы сохраняются как Blob в IndexedDB, изображения восстанавливаются после reload. До 20 МБ каждый, 10 файлов за вставку.
- Меню → «Скачать доску»: формат `.ryadom` с оригиналами вложений до 35 МБ суммарно. Импорт добавляет объекты к существующим; входной файл до 50 МБ.
- Локальная совместная работа **между вкладками того же браузера и адреса**: курсоры, процесс рисования, обновления отдельных объектов. Конфликт текста сохраняет второй вариант рядом.
- Существующий C++ API: вход по email/паролю, явное создание нового снимка и добавление снимка по ID. Снимки на сервере не включают оригиналы вложений; обычные заметки не перезаписываются.

## Граница совместной работы

Работа разных людей **между устройствами ещё не подключена**: текущий C++ сервер не имеет протокола операций, WebSocket и файлового API. Запуск бэкенда не делает локальную синхронизацию сетевой. Точные изменения описаны в [отдельном файле бэкендеру](docs/BACKEND_BOARD.md).

Смена порта или браузера меняет хранилище. Очистка данных сайта удалит локальные доски и вложения. Скачивайте резервные копии. Старые заметки `ryadom.notes.v1` не удалены; прежний интерфейс доступен в Git-истории.

## Клавиши

V — выделение, H/Пробел — перемещение, N — стикер, T — текст, P — карандаш, R — прямоугольник. Ctrl/⌘+Z — отмена, Shift+Ctrl/⌘+Z — повтор, 1 — показать всё, Delete — удалить выбранное. Перетаскивание свободного места двигает доску.

## Проверки и документация

```sh
npm test
node scripts/launcher-test.mjs
node scripts/proxy-test.mjs
```

Браузерный тест использует только уже установленные инструменты, в отдельном временном профиле:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright/index.mjs \
BROWSER_PATH=/absolute/path/to/chromium-compatible-browser \
BOARD_TEST_ORIGIN=http://127.0.0.1:4173 \
node scripts/board-test.mjs
```

Сначала запустите фронтенд. Тест не ходит на внешние сайты и проверяет API на mocks. Скриншоты — в игнорируемой `test-results/`. Проверяется содержимое экспортного Blob; завершение нативного загрузчика headless Vivaldi не подтверждается.
